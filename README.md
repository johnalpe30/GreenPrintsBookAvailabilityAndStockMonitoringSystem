# GreenPrints Book Availability and Stock Monitoring System

A prototype interface for a system that lets Holy Trinity College students
check the real-time stock of academic books at GreenPrints before making
a trip to the shop.

This repository contains only the **initial prototype interface** — a
static front-end mockup. No login, backend, or database functionality is
implemented yet; this is intended purely to present the proposed look and
feel of the application.

## Target organization
GreenPrints (campus academic bookstore) — Holy Trinity College

## Running locally
Open `index.html` directly in a browser, or use VS Code's Live Server
extension (right-click `index.html` → "Open with Live Server").
